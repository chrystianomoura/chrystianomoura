## Sobre

Desenvolvo interfaces para a Web e tenho o JavaScript como principal linguagem de estudo e construção.

Tenho usado JavaScript puro para entender a Web além das abstrações. Em cada projeto, busco explorar problemas diferentes de arquitetura, organização de código, responsividade, acessibilidade, performance e experiência do usuário.

A cada novo projeto, procuro aumentar o nível de desafio e ampliar o que consigo construir para a Web.
